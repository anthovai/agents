Interactive video — ตัวอย่าง

ตัวอย่างนี้ ไม่เรียกเซิร์ฟเวอร์จริง — ใช้ api ปลอมที่ตรวจคำตอบในหน้านี้เอง เพื่อให้เห็นพฤติกรรมของตัวเล่นโดยไม่ต้องมี backend
ตอนใช้งานจริงห้ามทำแบบนี้ เพราะเฉลยจะอยู่ในหน้าเว็บ ให้ใช้ InteractiveVideo.createApi({baseUrl: '/api/video'}) ซึ่งยิงไป backend ของคุณ แล้วให้ backend เรียกบริการนี้อีกที (ดู src/api.js)

วิดีโอทดสอบมีคำถาม 3 จุด — วินาทีที่ 3 (ข้อความ), วินาทีที่ 6 (เลือกข้อเดียว) และ วินาทีที่ 10 (พิมพ์ตอบ) ลองกดเล่นแล้วดูว่ามันหยุดเองตรงจุดไหน และลองกดถอยหลังแล้วเล่นข้ามดู
